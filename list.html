Технологии Web-графики

Технология Тип графики Принцип работы Масштабируемость Где используется
WebP Растр (Web-формат) Сжатие с потерями/без потерь Ограничена исходным разрешением Фотографии на сайте, баннеры, картинки
SVG Вектор (DOM/XML) XML-разметка в DOM-дереве браузера Идеальная на любых Retina/4k мониторах Иконки, логотипы, UI-элементы, векторные иллюстрации, анимации
HTML5 Canvas Растровая процедурная Изображение рендерится через JavaScript на пиксельном холсте Требует ручного пересчёта пикселей при масштабировании 2D-игры, графики/диаграммы в реальном времени, фоторедакторы
Растровая графика (концепция) Растр Сетка пикселей (Color Grid) Теряет качество при увеличении Фотографии, сложные реалистичные изображения
Векторная графика (концепция) Вектор Математические формулы (точки, линии, кривые) Бесконечная без потери качества Логотипы, иконки, схемы, шрифты
