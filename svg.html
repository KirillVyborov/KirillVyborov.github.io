SVG

SVG (Scalable Vector Graphics — «масштабируемая векторная графика») — открытый стандарт векторной графики для веба, разработанный консорциумом W3C. Утверждён в 2001 году, но по-настоящему массовым стал после появления смартфонов и экранов с высокой плотностью пикселей.

Главная особенность SVG в том, что это не просто формат картинки, а полноценный XML-код. SVG-изображение можно вставить в страницу как файл через тег img, как фоновую картинку через CSS или прямо в HTML-разметку — и тогда с каждым элементом можно работать через CSS и JavaScript: менять цвет, анимировать, обрабатывать клики.

Плюсы:

  • идеальная чёткость при любом масштабе и на любом экране;
  • очень маленький размер для простых изображений;
  • стилизация и анимация средствами CSS и JS;
  • доступность: внутри SVG можно размещать текст и описания для скринридеров;
  • открытый стандарт без лицензионных отчислений.

Минусы:

  • непригоден для фотографий;
  • чем сложнее рисунок (много фигур, градиентов, фильтров), тем больше файл и нагрузка на отрисовку;
  • безопасность: SVG, вставленный в разметку, выполняет скрипты, поэтому его нельзя бездумно загружать из недоверенных источников.

Типичное применение — иконки, логотипы, кнопки, схемы, графики, декоративные иллюстрации и анимация интерфейсов. Сегодня SVG — фактический стандарт векторной графики в вебе.
