# Сайт о графике в Web

Создан, используя фреймворк [xp.css](https://botoxparty.github.io/XP.css/)

## Есть два варианта запуска сайта:

- Локально, через открытие файла **index.html**

## Используемые технологии:

- HTML5 - язык разметки
- Фреймворк xp.css

- JavaScript для кнопки бургер-меню
